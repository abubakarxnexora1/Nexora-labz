NEXORA LABZ — HERO VIDEO SLOTS
==============================

Every page has a <video class="hero-video" data-video-slot> element with a
clear comment above it. To use your own cinematic background, drop your
files here using these names:

  home.mp4      → Home page hero        (assets/videos/home.mp4)
  about.mp4     → About page hero       (assets/videos/about.mp4)
  services.mp4  → Services page hero    (assets/videos/services.mp4)
  projects.mp4  → Projects page hero    (assets/projects hero)
  figma.mp4     → Figma page hero       (assets/videos/figma.mp4)
  contact.mp4   → Contact page hero     (assets/videos/contact.mp4)

Rules
-----
• Format: MP4 (H.264) and/or WebM. Keep files under ~4 MB for speed.
• Muted + looped clips work best (no sound is ever played).
• If a video file is MISSING, the site automatically hides the <video>
  element and the Three.js / canvas animation behind it stays visible —
  the hero never looks empty. That is why videos are optional.

Free 4K stock footage sources (license-safe, check each license):
  • https://www.pexels.com/videos/
  • https://pixabay.com/videos/
  • https://coverr.co/

Tip: use <source src="assets/videos/home.webm" type="video/webm"> plus the
MP4 source inside each <video> tag for maximum browser support.
